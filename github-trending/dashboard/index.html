How this list is built. Repositories created in the last 24 hours, 7 days or 30 days, fetched live from the GitHub Search API and ranked by stars. The rank column always shows the stars rank, so you can sort by another column and still see where a repo stands.

Downloads. GitHub publishes no download count for repositories, only for release files. Forks are the nearest public signal of people taking a copy. Stars/day is stars divided by the repo's age, a rough velocity.

Results are cached in this browser for 60 minutes per tab and language. Refresh forces a new fetch.
